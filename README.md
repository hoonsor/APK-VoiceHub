# 語音總控

對手機說一句話，就幫你開 APP、設鬧鐘、導航、調音量、派工給利姆路……做完用說的告訴你結果；做不到也會直說。
畫面跟 Gemini Live 一樣從底部浮出，有隨聲音流動的光影。

## 安裝
1. 手機瀏覽器打開 GitHub `hoonsor/APK-VoiceHub` 的 Releases，下載 `VoiceHub-latest.apk`（新功能先裝 `VoiceHub-LAB-latest.apk`，兩個可以同時安裝）
2. 允許「安裝未知應用程式」後安裝
3. 第一次打開會要麥克風權限，請允許

## 首次設定（OPPO／ColorOS）
1. **API key**：打開「語音總控設定」（長按桌面圖示 › 設定，或對話畫面左下齒輪）› 設定
   - 主力 AI：MiniMax 的 API key（網址與模型已預填，可改），按「測試」看到「成功」即可
   - Groq：Groq 的 API key（語音轉文字＋備援），按「測試」
   - 都不填也能用，但只能聽懂固定句型（開 APP、鬧鐘、計時、手電筒、播放控制、撥號、派工）
2. **長按電源鍵叫出**：設定 › 應用程式 › 預設應用程式 › 數位助理應用程式 › 選「語音總控」；再到 設定 › 其他設定 › 電源鍵 › 長按電源鍵 › 選「語音助理」
3. **快速設定磚**：健康檢查 › 快速設定磚 › 加入
4. **ColorOS 自啟動與關聯啟動**：手機管家 › 權限隱私 › 自啟動管理，打開語音總控與要被控制的 APP（鬧鐘、照片整理箱等）的「允許自啟動」「允許關聯啟動」
5. **派工**：手機的 Tailscale 要開著；健康檢查 › 語音派工 › 測試連線
6. **音量鍵叫出（選用）**：設定 › 音量鍵叫出 › 打開，再按「允許上層顯示」「電池不限制」；藍牙耳機或手機側鍵按「加、減、加」就會叫出（偵測紀錄可確認耳機音量收得到）
7. 健康檢查頁全部是綠燈就完成了

## 怎麼用
- 叫出：長按電源鍵、點桌面圖示、下拉選單的「語音總控」磚，或音量鍵按「加、減、加」。一打開就在聽
- 說完停一下會自動送出；也可以按中間的方塊按鈕表示講完了
- 不方便講話：按鍵盤按鈕打字
- 點上方空白處或按 ✕ 關閉；開了別的 APP 後對話視窗會自動收起（可在設定關掉）
- AI 問你問題時（例如「要哪一個？」）會自動再聽；開啟「連續對話」則每次回覆完都再聽

## 使用說明書
APP 下方的「說明書」分頁是完整的工具書：每個動作的講法、限制、情境範例、做不到的事與常見問題，可以搜尋；點例句會帶進對話畫面，按送出才執行。
每一章會即時標示這支手機上的狀態（可用／規劃中／未安裝）。
在電腦上也能看：[docs/manual/MANUAL.md](docs/manual/MANUAL.md)。

## 語音指令範例
| 說 | 會做 |
|---|---|
| 打開 LINE／開相機 | 開啟 APP（名字可以不完整，同名多個會問你） |
| 明天早上七點叫我／平日六點半的鬧鐘 | 用時鐘 APP 設鬧鐘 |
| 計時五分鐘／三分鐘後提醒我 | 計時器 |
| 打電話給媽媽 | 打開撥號畫面，你按撥出（要先允許聯絡人權限） |
| 傳簡訊跟老婆說我晚點到 | 打開簡訊草稿，你按傳送 |
| 導航到台北車站／開車去機場／走路去全聯 | 地圖導航（沒說怎麼去就用機車，可在設定改預設交通方式） |
| 開手電筒／媒體音量調到三十／下一首 | 手機控制 |
| 打開藍牙設定／還剩多少電 | 系統設定與狀態 |
| 下週三下午兩點開人事會議 | 打開行事曆新增畫面 |
| **派工**，幫鬧鐘 APP 加一個貪睡次數上限 | 原話送到利姆路派工網站，唸出幾號單 |
| **我有個點子**，做一個記帳工具可以拍收據 | 同上 |
| 第 12 號派工單進度如何 | 查派工單狀態 |
| 今天星期幾 | 直接回答 |

派工觸發詞：派工、幫我派工、記一個開發需求、我有個點子、叫利姆路……（說完觸發詞停住，它會問你要派什麼）。派工網站連不上時會先存在手機，下次打開對話畫面自動補送。

控制你自己的其他 APP：那些 APP 補上 Hoonsor Agent API 並用同一把簽章安裝後，到「動作」頁按「重新掃描」，就能直接用說的操作它們。

## 設定頁其他項目
- 語音辨識引擎：Groq（準確）／Android 內建（免費，沒 Groq key 時自動使用）
- 唸出回覆、朗讀速度、連續對話、跳到其他 APP 後自動關閉
- **朗讀聲音**：列出手機上所有中文聲音（台灣中文排最前面，標示離線可用或需連網），每個都能「試聽」，點一下就換成那個聲音、立刻生效。手機上有好幾個朗讀引擎時可以先選引擎。聲音太少：按「開啟系統文字轉語音設定」› Google 語音服務 › 安裝語音資料 › 中文（台灣），下載完回到這頁清單會自動更新。健康檢查的「測試朗讀」會顯示目前用的是哪個聲音
- 測試台：不經 AI 直接執行任一動作（可試跑），開發與除錯用

## 備份與還原
目前只有 Android 系統備份（設定值）。API key 為了安全不會備份，換手機要重新輸入。完整備份匯出／匯入在下一版。

## 隱私與資料規範

### 什麼時候錄音
- 只在對話畫面開著、正在聆聽（底部光影亮起）時錄音；離開對話畫面就停止，**不會在背景偷聽**
- 錄音不存檔，只在記憶體裡送去轉文字；對話內容也只放在記憶體，關掉 APP 就消失
- 手機上唯一會存下的文字，是派工網站連不上時暫存、等待補送的派工原話（送出後就刪除）

### 資料會送到哪裡
| 資料 | 送到 | 備註 |
|---|---|---|
| 語音錄音 | Groq（美國）轉文字；沒填 Groq key 時用 Android 內建辨識 | Groq 非大陸廠牌；內建辨識由手機的系統語音服務提供（可能是 Google 或手機廠商），以系統設定為準 |
| 辨識後的文字、最近 6 輪對話、可用動作清單 | 主力 AI（預設 **MiniMax 國際版** `api.minimax.io`）；失敗時改用 Groq | MiniMax 是大陸廠牌的國際版 |
| 派工原話 | 你自己的派工網站（只在 Tailscale 內），之後由背景的 Claude 處理 | 不經過上面的 AI |
| 執行動作（開 APP、鬧鐘…） | 只在手機上執行 | — |
| 聯絡人 | 只在手機上查詢，不上傳；但你說出口的名字會出現在送給 AI 的文字裡 | — |
| API key | 手機 Keystore 加密，不進系統備份 | — |

### 可以講什麼、不要講什麼（依 AI-PROFILE §4）
- **可以**：個人生活、操作手機、開發需求與點子、公開資訊
- **不要用語音講人事資料**：姓名＋生日、身分證字號、薪資、考績、獎懲、請假或病假原因、住址、電話。語音會原樣送出，**沒辦法先在本機去識別化**；而 MiniMax 國際版依規範只能處理「已去識別化」的公務文字
- **公文內容、學校內部資訊**：預設設定下不要講。真的要用語音處理一般公文，請先把主力 AI 改成非大陸廠牌的服務，而且內容不含人事資料；**密件一律不上線**
- **派工**也一樣不要夾帶人事資料，因為會交給背景的 Claude 處理

### 設定頁的警告
- 填入**大陸廠牌雲端服務**的網址（例如 MiniMax 中國版、DeepSeek、通義、智譜、豆包、Kimi）：顯示紅框，提醒公務資料即使去識別化也不能送
- 填入 **MiniMax 國際版**：顯示橘框，提醒只限去識別化文字、不要用語音講人事資料
- 本機或區網位址（例如自己電腦跑的離線模型）：不提醒，因為資料不會離開你的網路

## 常見問題
- **長按電源鍵沒反應**：確認「預設數位助理」選的是語音總控、電源鍵長按設定為語音助理；健康檢查頁該項要綠燈
- **音量鍵手勢沒反應**：看設定頁的偵測紀錄有沒有出現音量變化；沒有就是耳機的音量手機收不到。音量最大時先調小一格；螢幕要解鎖
- **說完沒反應／一直在聽**：環境太吵時自動判斷會比較慢，直接按中間按鈕結束
- **辨識成奇怪的句子**：Groq 沒聲音時可能幻聽，已自動濾掉常見的；請再說一次
- **說「AI 目前連不上」**：檢查網路與 key（設定 › 測試）；仍可用固定句型
- **派工說連不上**：打開 Tailscale；暫存的會自動補送，健康檢查頁也能「立即補送」
- **其他 APP 沒出現在動作清單**：兩個 APP 必須是同一把簽章；ColorOS 要允許關聯啟動
- **隱私**：見上面「隱私與資料規範」；簡單說，不要用語音講人事資料，預設設定下也不要講公文內容
