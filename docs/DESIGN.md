# 設計規範 — 語音總控

> 狀態：v0.1.0 依倬的 UX 預設直接實作，**尚未做 Claude Design 多方案比較**（SOP 第 3 階段待補）。截圖見 PROJECT_STATUS.md 的實機確認清單。

## 色票（唯一來源：`app/src/main/java/tw/hoonsor/voicehub/ui/theme/Theme.kt` 的 `C`）
全部用 HSL 調出，不用原色。

| 名稱 | HSL | 用途 |
|---|---|---|
| bg | 225° 26% 7% | 頁面底色 |
| surface／surfaceHi | 226° 22% 11%／226° 20% 15% | 卡片／選取中 |
| field | 226° 24% 9% | 輸入框 |
| border／borderHi | 226° 18% 21%／226° 16% 30% | 邊框（按鈕一律有邊框） |
| text／textSoft／muted／dim | 222° 30% 94%／18% 82%／12% 62%／10% 46% | 文字層級 |
| auroraBlue | 222° 92% 66% | 主色、光影 |
| auroraViolet | 268° 86% 70% | 光影 |
| auroraPink | 328° 78% 68% | 光影 |
| auroraTeal | 172° 64% 56% | 光影、「查詢」標籤 |
| ok／warn／danger | 150° 56% 58%／32° 90% 64%／8° 82% 68% | 成功／注意／危險 |

## 字級
標題 22sp SemiBold；對話中 AI 回覆 18sp（行高 26）、使用者 16sp；內文 14sp；標籤 12sp Medium；等寬 12sp（測試台 JSON）。

## 間距與圓角
頁面左右 16dp；卡片內距 16dp、圓角 16dp；卡片間距 12dp；按鈕高 40dp 圓角 20dp；對話泡泡圓角 18dp（說話方向那角 4dp）；底部導覽列圓角 20dp。

## 對話畫面
- 半透明疊層：上方透出原畫面（輕觸關閉），下方漸層到 96% 不透明
- 底部極光：三團 sweep 漸層光球，9 秒轉一圈、2.4 秒左右擺動、48dp 模糊；強度：待命 0.32、聆聽 0.55＋音量、思考呼吸、執行 0.85、朗讀波動
- 麥克風鈕：76dp 極光外環＋68dp 內圓；聆聽中變白底黑方塊（按下＝講完了），隨音量放大
- 控制列：設定、打字、麥克風、關閉，四顆 52dp 圓鈕
- 動作晶片：成功綠框打勾、失敗橘框打叉，顯示動作名稱與 summary

## 元件規則
- 圖示：`ui/Icons.kt` 手繪線條（24×24、1.8 線寬、圓角端點），不用 Material 圖示庫
- 每個設定都有「測試」按鈕；健康檢查用三色狀態點（綠正常、橘注意、紅異常）
- 風險標籤：查詢（青）、可復原（藍）、需確認（紅）
- 狀態列與導覽列一律淺色圖示（`SystemBarStyle.dark`）
